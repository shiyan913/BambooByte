# BambooByte — Multi-Page Chinese Learning Website

BambooByte is a Chinese-learning website built with HTML, CSS and JavaScript. This version is intentionally **not an SPA**: navigation loads separate HTML documents.

## Pages
1. `index.html` — Home
2. `learning.html` — Learning dashboard
3. `lesson.html` — Lesson practice
4. `mocktest.html` — HSK mock test
5. `advanced.html` — Advanced hub
6. `grammar.html` — 50 grammar patterns
7. `reading.html` — 12 reading passages
8. `idioms.html` — 50 idioms / 成语
9. `profile.html` — Learner profile
10. `settings.html` — Learning preferences

Shared styling is in `style.css` and shared interactions are in `script.js`.
