OFFLINE HSK 3 REFERENCE

HSK 3 · Practical intermediate

Handle basic communication in life, study and work with longer sentences.

Key topics

  • School and work
  • Travel situations
  • Health and appointments
  • Plans and experiences
  • Descriptions and opinions

Grammar to revise

  • 把 sentences (intro)
  • 被 sentences (intro)
  • 越来越…
  • 一边…一边…
  • 先…再…

Revision strategy

Start writing short sentences from prompts and reading for the main idea instead of translating every word.

Offline study checklist

  • Review vocabulary in short daily sessions
  • Read examples aloud
  • Write 5 original sentences
  • Complete the BambooByte HSK 3 mock test
  • Review mistakes before moving on
